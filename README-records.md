# سجل إنجاز المستقل — لقطة مشفّرة بكلمة مرور

## الحماية — 2026-10-08

اختار المستخدم موقعًا عامًا ببيانات محمية، ووافق على استخدام GitHub Actions
وGitHub Secrets لجلب الشبكات. الكود عام؛ سجل اللعب يجب أن يُنشر **مشفّرًا فقط**.
نُشر كود الواجهة المشفّرة على GitHub Pages. لم تُنشر لقطة المستخدم بعد؛ اختيار
عبارة المرور وتصدير `snapshot.enc.json` يسبقان نشرها. إعداد Secrets وربط الحسابات
وإعادة حساب إنجاز المستقلة لم تُنفّذ بعد.

أدخل عبارة مرور من 14 حرفًا على الأقل، ويفضّل كلمات عشوائية متعددة لا تستعملها
في حساباتك. عند استيراد JSON غير مشفّر لأول مرة، أعد العبارة في خانة التأكيد.
راجع المعاينة واعتمدها: تُحفظ النسخة الحالية والسابقة مشفّرتين. «تصدير نسخة مشفّرة»
يعطي `snapshot.enc.json`، وهو الملف الوحيد من السجل المسموح بنشره.

AES-256-GCM، nonce عشوائي 96 bit وsalt عشوائي 256 bit، ومفتاح مشتق عبر
PBKDF2-SHA256 بعدد 600,000 دورة. لا تُحفظ كلمة المرور ولا تُرسل إلى الموقع.
السجل يُفتح في الذاكرة فقط، ويُقفل عند مغادرة الصفحة أو بعد 15 دقيقة بلا تفاعل.
النسخة المحلية في `gamelib-encrypted-snapshots` لا تحتوي JSON مكشوفًا.
الحماية تخص صفحة السجل الجديدة، لا بيانات المكتبة القديمة في `index.html`.

هذه ليست خدمة تسجيل دخول: يستطيع أي شخص تنزيل الملف المشفّر ومحاولة تخمين
العبارة خارج الموقع. لذلك رُفضت الرموز الرقمية القصيرة، ولا توجد استعادة للعبارة.
تغيير كلمة المرور لا يلغي نسخًا قديمة نُشرت أو نُزّلت. الملفات الخام الأصلية المحلية
ليست مشفّرة تلقائيًا؛ لا تنقلها إلى المستودع.

تجلب الصفحة يدويًا `data/snapshot.enc.json` من نفس الموقع، تفكّه محليًا ثم تعرض
معاينة قبل استبدال النسخة المحلية. هذا **جلب لقطة منشورة**، لا جلب الشبكات نفسه.

افتح `records.html` من الموقع، ثم اختر ملف `gaming-snapshot` وراجع المعاينة
واضغط «اعتماد اللقطة». لا تستخدم `profile.json`: قد يحتوي أسرارًا ولا يقبله المستورد.
السجل يُحفظ مشفّرًا في IndexedDB على الجهاز؛ الاستيراد لا يرفعه إلى GitHub ولا يتصل بالتطبيق الأصلي.
يُحفظ الإصدار السابق عند كل اعتماد، ويمكن معاينته واستعادته. صدّر نسخة احتياطية قبل
مسح بيانات المتصفح أو الانتقال إلى هاتف آخر.

## ما يعمل الآن

- عرض الرتبة والنقاط والإنجازات الفعلية من محرّك إنجاز وقت التصدير، مع الخامات والندرة.
- البحث والترشيح في الألعاب والإنجازات، وإحصائيات المصادر والأجهزة والسنوات والأشهر.
- فصل الوقت غير المؤرّخ عن التقويم؛ لا اختلاق أيام أو تحويل إجماليات إلى جلسات.
- العمل دون إنترنت بعد أول تحميل ناجح، مع تحديث اختياري للموقع.
- عدم تعديل مكتبة `index.html` أو عدّادها أو بياناتها. «المِران» فيها نظام قديم منفصل؛
  لم يُرحّل إلى محرّك إنجاز بعد. لا تجمع أرقام المكتبتين.

## ما لم يكتمل

هذه **لقطة للقراءة فقط**، وليست جلبًا حيًا من الشبكات أو محرّك نقاط مستقلًا يعيد الحساب.
الربط المستقل لـXbox وSteam وPlayStation وNintendo يحتاج منفّذًا آمنًا خارج ملفات
GitHub Pages العامة. لا تضع مفاتيح أو رموز دخول في HTML أو JavaScript أو JSON منشور.
لم تُنشر بيانات شخصية مع هذا الكود. وافق المستخدم على نشر ملف مشفّر وعلى منفّذ
GitHub Actions، ولم يُعدّ المنفّذ أو تُنقل المفاتيح بعد. تاريخ التصدير لا يعني أن حسابات
الشبكات جرى تحديثها في ذلك الوقت.

## التحقق

`node tests/run.cjs` — اختبارات المكتبة الأصلية.

`node tests/snapshot.cjs` — عقد اللقطة والأمان؛ يمكن تمرير ملف خاص محليًا للتحقق منه.

`node tests/browser.cjs [private-snapshot.json]` — اختبار Edge معزول. يحتاج Playwright
مثبتًا مسبقًا؛ `PLAYWRIGHT_MODULE` اختياري لمساره. لا ينزّل متصفحًا ولا يستخدم ملفك الشخصي.
يشمل معاينة/إلغاء/اعتماد، إعادة التحميل، رفض الملفات التالفة، استعادة السابقة، والأوفلاين.

`node tests/crypto.cjs` — فك صحيح/كلمة خاطئة/عبث بالمحتوى، salt وnonce متغيران،
تحديد كلفة KDF، عدم تسريب metadata، وتوافق مع تنفيذ Node crypto المستقل.

`scripts/seal-snapshot.cjs` أداة تشفير جاهزة للمنفّذ المستقبلي؛ تأخذ كلمة المرور من
`SNAPSHOT_PASSPHRASE` في البيئة، ولا تطبع أسرارًا أو تفاصيل الاستثناءات. ليست
workflow لجلب الشبكات، ولم تُربط بمفاتيح المستخدم.
